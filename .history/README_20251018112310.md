# Minishell

A tiny POSIX-style shell written in C. This minishell supports pipelines, redirection (including here-docs), background execution, simple conditionals, variable expansion, and basic built-ins.

## Features

- **Built-ins:** `cd`, `export`, `pushd`, `popd`, `exit`
- **Pipes:** `cmd1 | cmd2 | cmd3`
- **Redirection:** `<`, `>`, `>>`, and **here-docs** `<<DELIM`
- **Background jobs:** `cmd &` (basic; no job control/fg/bg)
- **Conditionals:** `cmd1 && cmd2`, `cmd1 || cmd2`
- **Variable expansion:** `$VAR`, `$?` (exit status)
- **Quoting:**
  - **Single quotes** `'...'` → literal (no expansion)
  - **Double quotes** `"...`" → expands `$VAR`, `$?`; supports `"`, `\`, `\n`, `\t`
- **Rightmost status for pipelines** (return code comes from the last stage)

## Non-Goals / Limitations

- No advanced parsing: **no globbing**, no command substitution, no subshells `(...)`, no braces `${VAR}`, no environment assignments preceding a command (`VAR=1 cmd`), no `2>`/`&>` redirection, no job control (`fg/bg/ctrl-Z`).
- Quoting is basic; escape handling applies **inside double quotes only**.
- This is a teaching shell — not a replacement for `bash`, `zsh`, or `fish`.

## Build

Requirements: a C11 compiler (GCC or Clang) on macOS or Linux.

```bash
gcc -std=c11 -Wall -Wextra -O2 -o minishell minishell.c
# or
clang -std=c11 -Wall -Wextra -O2 -o minishell minishell.c
```

## Run

```bash
./minishell
```

You’ll see:

```
mini$ 
```

Type `exit` (or press Ctrl-D on an empty line) to quit.

## Quick Tour

### Pipes and redirection
```bash
mini$ echo hello | tr a-z A-Z > out.txt
mini$ cat < out.txt
HELLO
```

### Variables and status
```bash
mini$ export WHO=world
mini$ echo "hi $WHO"
hi world
mini$ false || echo "last status was $?"
last status was 1
```

### Quoting
```bash
mini$ echo 'literal $HOME and $?' 
literal $HOME and $?
mini$ echo "expanded $HOME and $?"
/Users/you and 0
mini$ echo "quote with \"escaped quotes\" and backslash \\ ok"
quote with "escaped quotes" and backslash \ ok
```

### Background
```bash
mini$ sleep 2 & echo "running in bg"
Backgrounded: 12345
running in bg
# ... later ...
Completed: 12345 (0)
```

### Conditionals
```bash
mini$ true && echo ok
ok
mini$ false || echo recovered
recovered
```

### Directory stack (`pushd`/`popd`)
```bash
mini$ pushd /tmp
/tmp /current/dir
mini$ popd
/current/dir
```

### Here-doc
```bash
mini$ cat <<EOF | wc -c
> abc
> 123
> EOF
8
```

## Implementation Notes (high level)

- **Tokenizer**: splits into words and operators (`| & < > >> << && ||`), with basic quoting rules (see above). Double-quoted sections expand `$...`; single-quoted do not.
- **Parser**: left-associative AST for background, `&&`/`||`, pipelines, and simple commands; redirections attach to the nearest simple command.
- **Executor**:
  - Built-ins run in the parent.
  - External commands use `fork()+execvp()`.
  - Pipelines use `pipe()` with two child processes per pipe boundary; returns the **rightmost** status.
  - Redirection uses `dup2()`; here-docs use a `mkstemp()` temp file that’s `unlink()`ed after `dup2()`.
  - Parent ignores `SIGINT` so Ctrl-C hits children; children restore defaults.
  - Background jobs print `Backgrounded: PID` and are reaped non-blocking (`waitpid(..., WNOHANG)`).

## Repository Layout (suggested)

```
.
├─ minishell.c      # the single-file implementation
├─ README.md
├─ Makefile         # optional (example below)
└─ tests/
   └─ smoke.sh      # optional quick tests
```

### Example `Makefile` (optional)

```make
CC ?= gcc
CFLAGS ?= -std=c11 -Wall -Wextra -O2

all: minishell
minishell: minishell.c
	$(CC) $(CFLAGS) -o $@ $<

clean:
	rm -f minishell
.PHONY: all clean
```

### Optional smoke test (save as `tests/smoke.sh`)

```bash
#!/usr/bin/env bash
set -euo pipefail
echo "[1] build"
make -s

echo "[2] run a few commands"
./minishell <<'EOS'
echo hello | tr a-z A-Z > out.txt
cat < out.txt
export X=42
echo "X is $X"
false || echo "err $?"
true && echo ok
echo 'literal $HOME'
echo "dbl $HOME"
exit
EOS
```
Make it executable:
```bash
chmod +x tests/smoke.sh
```
